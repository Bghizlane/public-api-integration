# Public API Integration

A simple Python project that connects to a public API using the Requests library.

## Features

- Connects to a public API
- Sends HTTP GET requests
- Handles API errors
- Uses a timeout
- Processes JSON responses

## Technologies

- Python
- Requests
- REST API
- Git
- GitHub
